# Reference

## Module Exports

### `default`

The default export is an initializer function that configures Genie tasks for CoffeeScript projects.

$\text{default}(Genie: \text{object}) \rightarrow \text{void}$

The initializer reads the target configuration from options, and defines specific build, clean, lint, audit, and test tasks on the provided Genie instance.

### `Options.get`

Retrieves configuration options for the CoffeeScript preset.

$\text{get}(Genie: \text{object}) \rightarrow \text{object}$

Merges default options with any options specified in `Genie.get("coffee")`.

## Genie Tasks

The initialization function registers the following commands with the Genie task manager. These are invoked via the Genie CLI rather than as standard JavaScript module functions.

### `coffee:build`

Builds the CoffeeScript source files according to the defined targets. It transpiles CoffeeScript to JavaScript. 

This task is automatically registered to run whenever the higher-level Genie `build` command is invoked, ensuring CoffeeScript transpilation is a native part of the standard build lifecycle.

### `coffee`

An alias for the `coffee:build` task.

### `coffee:clean`

An alias for the `clean` task.

### `coffee:lint`

Lints CoffeeScript source files using ESLint. Line and column coordinates are transposed back to the original `.coffee` files using composite source maps, accompanied by excerpts of the offending CoffeeScript code. This task is defined as a hook for Genie's standard `lint` lifecycle task (`Genie.on "lint", "coffee:lint"`) rather than an alias, allowing other linters to run in concert. Supports dual-mode reporting: an interactive terminal UI with colored box-drawing characters, or structured streaming XML `<issue task="lint" ...>` blocks when `CI=true`, `NO_COLOR`, or `TERM=dumb` is set.

### `coffee:test`

Runs tests using the compiled output in `build/node/test/index.js` if it exists. Sets standard Node.js flags for source maps and trace warnings. This task is automatically registered to run with the higher-level Genie `test` command.

### `coffee:lint:fix`

Reads the cached output markers generated by `coffee:lint` and deterministically applies auto-fix regex replacements to the original `.coffee` source files for any solvable custom rule violations.

### `coffee:lint:clean`

Purges the internal linting cache by deleting the `.genie/coffee/lint` directory.

### `coffee:audit`

Semantically evaluates the CoffeeScript source files against architectural DashKite coding guidelines (defined in `src/helpers/audit-rules.yaml`) using an embedded generative language model. Emits validation errors in structured XML format. This task is hooked into the standard `audit` lifecycle task.

### `coffee:audit:clean`

Purges the internal semantic audit cache by deleting the `.genie/coffee/audit` directory.
